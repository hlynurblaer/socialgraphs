Overview

193 UN member states, one node each, with a directed edge A → B when A's Wikipedia article links to B's. Built and computed exactly as described in build_un_network.ipynb and analyze_network.py — re-run the latter any time the edge list changes to refresh these numbers.

Paths & Distances

Computed on the undirected giant component (G.to_undirected(), largest connected component) — same treatment exercise 3.3 gives the Marvel network, since path length and diameter need a graph where every reachable pair actually has a path to measure.

Centrality Leaderboards

Top 15 by each measure, with the underlying value shown — not just a bare ranking. Each measure answers a different question about a country's position in the network.

Cliques

A clique is a set of countries that are all pairwise linked to each other. Two different, deliberately separate notions of "linked" are used below, since they answer different questions and give very different answers.
